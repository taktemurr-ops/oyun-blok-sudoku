# oyun-blok-sudoku – Blok Sudoku

9x9 tahtada parçaları yerleştir; dolu satır, sütun **ve 3x3 kutular** temizlenir.
Motor Blok Bulmaca (game-001) ile ortaktır; bu depo oyunun kimliğini, adını ve öğreticisini tanımlar.
Blok Oyunları merkez uygulamasında (`merkez-blok-oyunlari`) yer alır.

Bölümler tohumla üretilir (100.000+), kampanya / sonsuz / zamana karşı / zen / günlük / haftalık modları vardır.
Kumar, şans mekaniği veya 18+ içerik yoktur.
